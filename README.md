## Краткое описание проекта  
Приложение представляет из себя мобильный музыкальный проигрыватель на операционной системе _Android_.  
Содержит два модуля: музыкальный проигрыватель и  музыкальный редактор.  
Музыкальный проигрыватель обладает следующими функциями: 
- Воспроизведение аудио
- Управление воспроизведением композиций
- Регулировка уровня локальной громкости песни
- Настройка времени начала и конца воспроизведения музыки

Музыкальный редактор обладает такими функциями как: «Объединить треки», «Обрезать аудио», «Разделить трек», «Конвертировать аудио», «Редактировать теги», «Эквалайзер», «Запись звука».  

## Технологический стек проекта  

Для разработки приложения _AKAP_ в качестве языка программирования был выбран _Kotlin_, а в качестве среды разработки — _Android Studio_. Помимо этого в проекте использовалась система контроля версий _Git_

## Установка  
Для установки музыкального проигрывателя _AKAP_ необходимо скачать _.apk_ файл, расположенный в этом репозитории, и запустить его на устройстве с операционной системой _Android_.  
Рекомендуется использовать на устройствах 13 версии _Android_ и выше, однако его все еще можно использовать и на более старых версиях.  
При запуске приложения необходимо предоставить разрешение на работу с медиафайлами на телефоне.
