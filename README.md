Краткое описание проекта  
Приложение представляет из себя мобильный музыкальный проигрыватель на операционной системе Android.  
Содержит два модуля: музыкальный проигрыватель и  музыкальный редактор.  
Музыкальный проигрыватель обладает базовыми функциями: воспроизведеним, паузы и переключением композиций, регулировки уровня их громкости.  
Помимо этого он позволяет пользователю настраивать локальную громкость каждой композиции, а также устанавливать точки начала или конца песен.  

Музыкальный редактор обладает такими функциями как «Объединить треки», «Обрезать аудио», «Разделить трек», «Конвертировать аудио», «Редактировать теги», «Эквалайзер», «Запись звука».  

Технологический стек проекта  
Для разработки приложения “AKAP” в качестве языка программирования выбран Kotlin, а в качестве среды разработки — “Android Studio”. Помимо этого в проекте использовалась система контроля версий Git

Установка  
Для установки музыкального проигрывателя “AKAP” необходимо скачать .apk файл, расположенный в этом репозитории, и запустить его на устройстве с операционной системой Android.  
Рекомендуется использовать на устройствах 13 версии Android и выше, однако его все еще можно использовать и на более старых версиях.  
При запуске приложения необходимо предоставить разрешение на работу с медиафайлами на телефоне.
