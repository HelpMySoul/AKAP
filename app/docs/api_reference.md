# _API_ документация музыкального проигрывателя _AKAP_  

## Введение  

_AKAP_ - мобильное приложение на операционной системе _Android_, обладающее следующими функциями:  
- Воспроизведение, пауза и переключение песен  
- Регулировка локальной громкости аудио  
- Настройка времени начала и конца воспроизведения музыки  
- Управление плейлистами  
- Настройка языка и темы приложения

<a name="playlistcontroller"><h4>PlaylistController</h4></a>
Этот контроллер управляет созданием, удалением, сохранением, изменением и поиском определенного или всех плейлистов. При создании контроллера необходимо указать контекст.

##### Создание плейлиста
Чтобы создать и отобразить в приложении новый плейлист необходимо вызвать _createPlaylist_ функцию со следующими параметрами:
- Название плейлиста
- Список песен
- Временность плейлиста

Может задаваться как списком песен, так и плейлистом.  

Временность плейлиста определяет будет ли он удален прекращении работы с ним. Временные плейлисты не отображаются в списке всех плейлистов.  

##### Удаление плейлиста
Для удаления плейлиста в приложения необходимо вызвать _deletePlaylist_ функцию с названием плейлиста, который необходимо удалить. 

Плейлист всех песен удалить нельзя.  

##### Сохранение плейлистов
Для сохранения плейлистов необходимо вызвать _savePlaylists_ функцию.  

##### Обновление названия плейлиста
Для обновления названия плейлиста существует _updatePlaylistName_ функция, принимающая в качестве параметров старое и новое название плейлиста, который необходимо обновить.  

##### Добавление песни в плейлист
Для того, чтобы добавить песню в плейлист необходимо вызвать _addSongToPlaylist_ функцию, принимающая в качестве параметров название плейлиста и песню, которую необходимо добавить.  

##### Получение плейлиста
Чтобы получить определенный плейлист по его названию, существует функция _getPlaylist_.  

Для получения списка всех плейлистов можно вызвать _getAllPlaylists_ функцию.  

<a name="songcontroller"><h4>SongController</h4></a>
Этот контроллер управляет проигрыванием композиций и работает с интерфейсом проигрывателя.  

##### Параметры создания контроллера

При создании контроллера необходимо:
- Указать контекст, в котором он будет воспроизводить музыку
- Указать песню и её плейлист
- Указать элементы интерфейса плеера

##### Назначение песни

Для изменения воспроизводимой песни необходимо вызвать _updateSong_ функцию, которая в качестве параметров принимает новую песню и плейлист, в котором она находится.  
После изменения песни интерфейс приложения автоматически обновится.  
При инициализации контроллера песня указывается как один из параметров, поэтому при создании контроллера песню дополнительно назначать не надо.  

##### Управление воспроизведением

Для управления воспроизведением песни существуют следующие функции:

| Действие                    | Функция         | Сообщение           |
| -------------               | -------------   | -------------       |
| Проигрывание                | _startPlaying_  | PLAY_SONG           |
|  Пауза                      | _pauseSong_     | PAUSE_SONG          |
| Возобновление проигрывания  | _unpauseSong_   | PAUSE_OR_PLAY_SONG  |
|  Остановка                  | _stopSong_      | STOP_SONG           |

Прямой вызов этих функций считается устаревшим, рекомендуется использовать соответствующее сообщение из [системы сообщений приложения](#управление-событиями-приложения).

Для управления повторением песни необходимо использовать _setRepeat_ функцию, которая принимает в качестве параметра булевую переменную.

##### Работа с метаданными песен

Для изменения времени начала или конца проигрывания у композиции существуют _setIntroTime_ и _setOutroTime_ функции, которые принимают в качестве параметра время в секундах.  
Также можно установить текущее время воспроизведения музыки, используя _setCurrentIntroTime_ и _setCurrentOutroTime_ соответственно.  

##### Отслеживание состояния воспроизведения

Для получения текущего времени воспроизведения существует функция _getCurrentTime_, которая возвращает время в секундах.
Для получения длительности композиции существует функция _getMaxTime_, которая возвращает время в секундах.

##### Обновление интерфейса

Интерфейс обновляется автоматически, но если необходимо его ручное обновление, это можно сделать функцией _updateUI_.

##### Освобождение ресурсов

Если контроллер больше не будет использоваться, его ресурсы можно освобождить функцией _release_.
