# _API_ документация музыкального проигрывателя _AKAP_  

## Введение  

_AKAP_ - мобильное приложение на операционной системе _Android_, обладающее следующими функциями:  
- Воспроизведение, пауза и переключение песен  
- Регулировка локальной громкости аудио  
- Настройка времени начала и конца воспроизведения музыки  
- Управление плейлистами  
- Настройка языка и темы приложения

<a name="контроллеры"><h3>Контроллеры функций воспроизведения аудио и управления плейлистами</h3></a>  

<a name="playlistcontroller"><h4>[_PlaylistController_](/app/src/main/kotlin/player/controllers/PlaylistController.kt)</h4></a>
Этот контроллер управляет созданием, удалением, сохранением, изменением и поиском определенного или всех плейлистов. При создании контроллера необходимо указать контекст.

##### Создание плейлиста
Чтобы создать и отобразить в приложении новый плейлист необходимо вызвать _createPlaylist_ функцию со следующими параметрами:
- Название плейлиста
- Список песен
- Временность плейлиста

Может задаваться как списком песен, так и плейлистом.  

Временность плейлиста определяет будет ли он удален прекращении работы с ним. Временные плейлисты не отображаются в списке всех плейлистов.  

##### Удаление плейлиста
Для удаления плейлиста в приложения необходимо вызвать _deletePlaylist_ функцию с названием плейлиста, который необходимо удалить. 

Плейлист всех песен удалить нельзя.  

##### Сохранение плейлистов
Для сохранения плейлистов необходимо вызвать _savePlaylists_ функцию.  

##### Обновление названия плейлиста
Для обновления названия плейлиста существует _updatePlaylistName_ функция, принимающая в качестве параметров старое и новое название плейлиста, который необходимо обновить.  

##### Добавление песни в плейлист
Для того, чтобы добавить песню в плейлист необходимо вызвать _addSongToPlaylist_ функцию, принимающая в качестве параметров название плейлиста и песню, которую необходимо добавить.  

##### Получение плейлиста
Чтобы получить определенный плейлист по его названию, существует функция _getPlaylist_.  

Для получения списка всех плейлистов можно вызвать _getAllPlaylists_ функцию.  

<a name="songcontroller"><h4>[_SongController_](/app/src/main/kotlin/player/controllers/SongController.kt)</h4></a>
Этот контроллер управляет проигрыванием композиций и работает с интерфейсом проигрывателя.  

##### Параметры создания контроллера

При создании контроллера необходимо:
- Указать контекст, в котором он будет воспроизводить музыку
- Указать песню и её плейлист
- Указать элементы интерфейса плеера

##### Назначение песни

Для изменения воспроизводимой песни необходимо вызвать _updateSong_ функцию, которая в качестве параметров принимает новую песню и плейлист, в котором она находится.  
После изменения песни интерфейс приложения автоматически обновится.  
При инициализации контроллера песня указывается как один из параметров, поэтому при создании контроллера песню дополнительно назначать не надо.  

##### Управление воспроизведением

Для управления воспроизведением песни существуют следующие функции:

| Действие                    | Функция         | Сообщение             |
|-----------------------------| ----------------| ----------------------|
| Проигрывание                | _startPlaying_  | `PLAY_SONG`           |
|  Пауза                      | _pauseSong_     | `PAUSE_SONG`          |
| Возобновление проигрывания  | _unpauseSong_   | `PAUSE_OR_PLAY_SONG`  |
|  Остановка                  | _stopSong_      | `STOP_SONG`           |

Прямой вызов этих функций считается устаревшим, рекомендуется использовать соответствующее сообщение из [системы сообщений приложения](#управление-событиями-приложения).

Для управления повторением песни необходимо использовать _setRepeat_ функцию, которая принимает в качестве параметра булевую переменную.

##### Работа с метаданными песен

Для изменения времени начала или конца проигрывания у композиции существуют _setIntroTime_ и _setOutroTime_ функции, которые принимают в качестве параметра время в секундах.  
Также можно установить текущее время воспроизведения музыки, используя _setCurrentIntroTime_ и _setCurrentOutroTime_ соответственно.  

##### Отслеживание состояния воспроизведения

Для получения текущего времени воспроизведения существует функция _getCurrentTime_, которая возвращает время в секундах.
Для получения длительности композиции существует функция _getMaxTime_, которая возвращает время в секундах.

##### Обновление интерфейса

Интерфейс обновляется автоматически, но если необходимо его ручное обновление, это можно сделать функцией _updateUI_.

##### Освобождение ресурсов

Если контроллер больше не будет использоваться, его ресурсы можно освобождить функцией _release_.

<a name="songsearchcontroller"><h4>[_SongSearchController_](/app/src/main/kotlin/player/controllers/SongSearchController.kt)</h4></a>

Этот контролер ищет песни в плейлисте. 
При его создании необходимо указать контроллер плейлистов.

Для поиска композиции по строке существует функция _search_, которая принимает в качестве параметров искомую строку и плейлист, в котором будет проводится поиск.
В качестве результата возвращает плейлист найденных песен.

Больше информации про поиск песен в приложении находится в [инструкции по применению музыкального проигрывателя _AKAP_](/app/docs/user_guide.md).

<a name="управление-событиями-приложения"><h3>Управление событиями приложения</h3></a>  

Все действия связанные с воспроизведением рекомендуется производить используя систему сообщений приложения.

Список доступных действий:

| Действие                     | Сообщение           |
|------------------------------|---------------------|
| Проигрывание                 | `PLAY_SONG`         |
| Пауза                        | `PAUSE_SONG`        |
| Возобновление проигрывания   | `PAUSE_OR_PLAY_SONG`|
| Остановка песни              | `STOP_SONG`         |
| Следующая песня              | `NEXT_SONG`         |
| Повтор песни                 | `REPEAT_SONG`       |
| Предыдущая песня             | `PREVIOUS_SONG`     |
| Перемешать плейлист          | `SHUFFLE_PLAYLIST`  |
| Обновить плейлист            | `REFRESH_PLAYLIST`  |
| Закрыть плейлист             | `CLOSE_PLAYLIST`    |
| Показать плеер               | `SHOW_PLAYER`       |
| Скрыть плеер                 | `HIDE_PLAYER`       |
| Обновить песню               | `UPDATE_SONG`       |
| Остановить уведомления       | `STOP_NOTIFICATION` |
| Перезапустить приложение     | `RESTART_APP`       |
| Перезапустить активность     | `RESTART_ACTIVITY`  |  

Для добавления нового действия в систему сообщений, необходимо зарегестрировать новый слушатель в [главной активности](/app/src/main/kotlin/akap/MainActivity.kt) с необходимым действием:  
```ruby
broadcastManagerController.registerReceivers("НАЗВАНИЕ_СООБЩЕНИЯ" to { playerEventController.event() })
```
Предварительно в [_PlayerEventController_](/app/src/main/kotlin/player/controllers/PlayerEventController.kt) должна быть добавлена необходимая вам функция (_event_ в примере).

Пример вызова существующего события:
```ruby
BroadcastManagerController(context).sendBroadcast("НАЗВАНИЕ_СООБЩЕНИЯ")
```

<a name="управление-отображаемым-фрагментом"><h3>Управление отображаемым фрагментом</h3></a>

<a name="appfragmentmanager"><h4>[_AppFragmentManager_](/app/src/main/kotlin/screens/AppFragmentManager.kt)</h4></a>

Переключением отображаемых фрагментов управляет менеджер фрагментов приложения.  
При создании новых фрагментов используется [_FragmentFactory_](https://developer.android.com/reference/androidx/fragment/app/FragmentFactory).  
Кроме того, менеджер фрагментов предотвращает создание дубликатов: если фрагмент уже был создан ранее, система откроет существующий экземпляр.  

Для добавления нового фрагмента в приложение необходимо создать новый класс, наследующий [_Fragment_](https://developer.android.com/reference/android/app/Fragment) в [фрагментах приложения](/app/src/main/kotlin/screens/fragments/).  
В этом классе надо использовать добавленный в [макеты приложения](/app/src/main/res/layout/) макет.  

Пример создания нового фрагмента:  
```ruby
package screens.fragments

import android.os.Bundle
import android.view.LayoutInflater
import android.view.View
import android.view.ViewGroup
import androidx.fragment.app.Fragment
import com.example.akap.R

class Example : Fragment() {
    override fun onCreateView(inflater: LayoutInflater, container: ViewGroup?, savedInstanceState: Bundle?): View {
        return inflater.inflate(R.layout.fragment_example, container, false)
    }
}
```

В [_TopMenuManager_](/app/src/main/kotlin/topMenu/TopMenuManager.kt) необходимо добавить в функцию полученния списка кнопок _getListOfButtons_ новую кнопку.  

```ruby
TopMenuButton(context.getString(R.string.example_button_name)) {
    openFragment(fragmentManager, containerId, Tools::class.java.simpleName) {
        Example()
    }
}
```
В ресурсах необходимо добавить строку с названием кнопки, например _example_button_name_.  
После этих действий в верхнем меню будет отображаться созданная вами кнопка, которая будет открывать указанный вами фрагмент.

<a name="thememanager"><h4>[ThemeManager](/app/src/main/kotlin/settings/theme/ThemeManager.kt)</h4></a>
Менеджер тем используется для смены и загрузки тем приложения.  

Для получения темы используется функция  _getTheme_, которая в качестве параметра принимает контекст.

Для сохранения указанной в параметре темы используется _saveTheme_, которой также необходим контекст.

Для добавления новой темы в приложение необходимо:
- Cоздать в [Стилях](/app/src/main/res/values/styles.xml) новую тему _NewTheme_ с требуемыми цветами (в примере это newThemePrimary, newThemePrimaryDark и newThemePrimaryLight):

```ruby
<style name="NewTheme" parent="AppTheme">
    <item name="colorPrimary">@color/newThemePrimary</item>
    <item name="colorPrimaryVariant">@color/newThemePrimaryDark</item>
    <item name="colorOnPrimary">@color/newThemePrimaryLight</item>
</style>
```

Новые цвета надо добавлять в [цветах приложения](/app/src/main/res/values/colors.xml).

- В функцию применения темы добавить вашу новую тему:
```ruby
fun applyTheme(theme: String, context: Context) {

        when (theme) {

            // Старые темы

            "New Theme"  -> context.setTheme(R.style.NewTheme)
            else         -> context.setTheme(R.style.AppTheme)
        }
    }
```
