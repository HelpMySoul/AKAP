# Инструкция по применению музыкального проигрывателя _AKAP_  

# Установка  

Для установки музыкального проигрывателя _AKAP_ необходимо скачать [_.apk_](https://github.com/HelpMySoul/AKAP/releases) файл и запустить его на устройстве с операционной системой _Android_.  

Рекомендуется использовать на устройствах 13 версии _Android_ и выше, однако его все еще можно использовать и на более старых версиях.  

# Первый запуск  

При запуске приложения необходимо предоставить разрешение на работу с медиафайлами на телефоне.  
Уведомление о запросе на предоставление прав появится автоматически.  

![Окно запроса на права](https://github.com/user-attachments/assets/bb0343af-80cc-4ca8-983e-2677bd735362)  

Для начала прослушивания музыки откройте окно всех плейлистов, нажав на соответствующую кнопку в верхнем меню:  
 
![Начальное окно](https://github.com/user-attachments/assets/f4b6b660-21f0-48e7-82d6-dc5aa7555ae3)

Выберите плейлист всех песен:  

![Окно плейлистов](https://github.com/user-attachments/assets/befce2ad-6fa2-4066-bfbc-d8ac76bb1037)

Они отобразятся в новом окне:  

![Все песни](https://github.com/user-attachments/assets/997711ab-afe7-45c7-a4ad-d0766fd165eb)  

Нажмите на любую песню и она воспроизведётся.  

# Основные функции воспроизведения  

Управление воспроизводимой композицией производится в интуитивно понятном меню проигрывателя:  

![Проигрыватель](https://github.com/user-attachments/assets/532b7dfc-7ee4-4723-82b2-bd27ec4ffa95)

Справа от названия песни расположены кнопки управления текущей песней.  
При нажатии на кнопку дополнительных настроек вы сможете настроить воспроизведение трека на свой вкус или перемешать текущий плейлист.   

Помимо этого в уведомлениях также будет отображаться проигрываемая песня:

![Уведомление](https://github.com/user-attachments/assets/4b24ccbb-3745-49db-8999-bf9f2235d58e)

# Поиск композиций

Для поиска необходимой композиции существует поисковое окно:  

![Поисковое окно](https://github.com/user-attachments/assets/a6ca738b-687b-4476-bad7-d32000439c86)

Помимо поиска по названию или автору, пользователь может указать тег дла поиска.  

Существующие теги (в скобках возможные сокращения):
- duration (dur / d)
- introduration (intro / i)
- outroduration (outro / o)

Пример использования тега:

![Поисковое окно: использование тега](https://github.com/user-attachments/assets/e9dc93bd-2ddd-4a56-9ffa-1fbd2a3fba71)

Список возможных условных операторов:
- ">" 
- "<"
- ">="
- "<="
- "=="
- "="
- "!="

В качестве параметра для поиска указывается время в секундах.

# Управление плейлистами

Текущий проигрываемый плейлист можно сохранить. Для этого откройте окно всех плейлистов и нажмите сохранить плейлист:

![Сохранение плейлиста](https://github.com/user-attachments/assets/416dee28-81d2-4a5f-b5bc-7491c009c631)

При долгом нажатии на плейлист можно выбрать сразу несколько, чтобы удалить их, нажав на кнопку с изображением мусорной корзины. 

# Меню настроек

При нажатии на кнопку настроек пользователю отоброзится соответствующее окно:  

![Меню настроек](https://github.com/user-attachments/assets/425616bd-90c4-4287-9e48-9c07d76fb105)

В нем пользователь может выбрать язык и тему приложения, а также удалить метаданные песен.
